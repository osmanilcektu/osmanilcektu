## Selected Open Source

### Discord Moderator Schedule Bot

Self-hosted Discord moderator scheduling and workload management bot built with **Node.js, discord.js, and SQLite**.

- Automated moderator shift scheduling
- Availability surveys and workload balancing
- Persistent SQLite state and restart recovery
- Admin diagnostics, reporting, and update checks
- Docker support
- GitHub Actions CI, Dependabot, releases, and security documentation

Repository: [osmanilcektu/discord-mod-takvimi](https://github.com/osmanilcektu/discord-mod-takvimi)  
Latest release: [v2.2.1](https://github.com/osmanilcektu/discord-mod-takvimi/releases/latest)

### SteelSeries GG Turkish Localization

Community-maintained Turkish localization project for **SteelSeries GG** on Windows.

Covers major interface areas including Engine, Sonar, Prism, Moments, device settings, notifications, and other UI components.

Repository: [osmanilcektu/steelseries-gg-turkce-yama](https://github.com/osmanilcektu/steelseries-gg-turkce-yama)  
Releases: [latest version](https://github.com/osmanilcektu/steelseries-gg-turkce-yama/releases/latest)
